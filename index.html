채팅 로그를 열기

룸 ID를 입력하면 채팅 표시용 주소를 열 수 있습니다. 코코포리아 정책상 외부 사이트에서 로그 HTML을 직접 추출하지 못할 수 있으므로, 공식 로그 출력으로 받은 HTML 파일을 이 페이지에 업로드해서 미리보는 기능도 같이 넣었습니다.

새 탭에서 열기

룸 ID는 공유 URL의 /rooms/여기 부분입니다.
예: https://ccfolia.com/rooms/ROOM_ID

iframe이 안 보이면 코코포리아가 외부 임베드를 막은 것입니다. 그때는 “새 탭에서 열기”를 사용해주세요.

코코포리아 룸 안에서 채팅 메뉴 → 로그 출력으로 받은 HTML 파일을 선택하면 아래에 표시됩니다.
