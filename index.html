코코포리아 로그
불러오기

코코포리아는 외부 사이트에서 룸 로그를 자동으로 긁어오는 것이 막힐 수 있습니다. 그래서 이 페이지는 룸 바로가기 생성과 다운로드한 HTML 로그 미리보기에 맞춰 만들었습니다.

룸 새 탭 채팅 새 탭

룸 ID는 공유 URL의 /rooms/여기 부분입니다.
예: https://ccfolia.com/rooms/ROOM_ID

룸 ID만으로 로그 HTML을 자동 다운로드하는 기능은 코코포리아 로그인/CORS/권한 문제 때문에 외부 정적 사이트에서는 거의 막힙니다.

코코포리아 룸 안에서 채팅 메뉴 → 로그 출력/저장으로 받은 HTML 파일을 선택하면 오른쪽에 표시됩니다.

아직 주소를 만들지 않았습니다. ccfolia

이 사이트 안에 코코포리아 룸을 직접 띄우는 기능은 뺐습니다.
대부분의 경우 외부 iframe이 차단되어 빈 화면만 뜨기 때문입니다.

아직 선택한 로그 파일이 없습니다. local html
